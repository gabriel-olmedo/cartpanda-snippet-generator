# Gerador de Snippet CartPanda

Ferramenta para gerar o `cartxCheckoutSnippet.liquid` com a slug correta de uma loja CartPanda.

## Funcionalidades

- Gera o snippet atualizado a partir da slug CartPanda.
- Valida a slug informada.
- Permite visualizar e copiar o código gerado.
- Baixa o snippet atualizado em `.liquid`.
- Disponibiliza um backup do snippet extraído da integração original.
- Ajusta a slug no backup antes do download.

## Como usar

1. Abra a ferramenta.
2. Informe somente a slug da loja CartPanda, por exemplo:

```text
teste-supp
```

3. Clique em **Gerar snippet atualizado**.
4. Baixe o **snippet atualizado** ou o **backup nativo**, conforme necessário.

> Informe apenas a slug, sem `https://`, `.mycartpanda.com` ou barras.
